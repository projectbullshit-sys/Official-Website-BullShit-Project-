THE FOG ARCHIVE

Explore the historical Dead by Daylight Mobile character roster. Select any portrait to open a detailed profile.

Roster and image note: This directory is restricted to the historical DBD Mobile roster documented by the Mobile character list. PC/console-only characters are excluded. Global and Asian releases could differ, so regional availability is noted where verified. Character licensing and regional releases varied.
